Backup WhatsApp

Copia locale del database sul tuo PC. Nessun software resta sul telefono.

  1. 1 · Collega l'iPhone

    Sbloccalo e, alla richiesta, tocca Autorizza questo computer.

  2. 2 · Password del backup

    Serve solo se sull'iPhone è già attivo il backup cifrato. Non la cambiamo.

  3. 3 · Opzioni

  1. 1 · Prepara il telefono

    Attiva Debug USB (Impostazioni → Opzioni sviluppatore) e, al collegamento, tocca Consenti. In WhatsApp puoi fare Impostazioni → Chat → Backup → Esegui backup per avere i messaggi più recenti.

  2. 2 · Quale backup copiare

  3. 3 · Chiave di cifratura (per leggere le chat)

    I backup di WhatsApp sono cifrati. Per decifrarli serve la chiave a 64 cifre del backup crittografato end-to-end (WhatsApp → Impostazioni → Chat → Backup → Backup crittografato end-to-end → «Visualizza chiave»). Senza chiave copio comunque i file, ma restano illeggibili.
